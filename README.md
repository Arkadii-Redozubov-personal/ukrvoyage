# УкрВояж / UkrVoyazh — DEMO-версія веб-платформи пасажирських перевезень

Інтерактивна демонстраційна версія двомовного (`UA / EN`) сайту транспортної компанії **«УкрВояж»** із системою онлайн-заявки на індивідуальні та колективні поїздки, стилізованими ілюстраціями категорій транспорту та демонстраційним журналом заявок оператора.

## Стек

- **Framework:** Next.js 16 (App Router, `proxy.ts`, Turbopack) + TypeScript
- **UI & Typography:** Tailwind CSS v4, `lucide-react`, локалізовані шрифти `Unbounded` та `Golos Text` (`next/font/google`)
- **Validation & Contracts:** `zod` (єдина схема для клієнтської та серверної валідації), `idempotencyKey`, антиспам-поле

## Запуск проєкту

```bash
npm install
npm run dev
```

Відкрийте [http://localhost:3000](http://localhost:3000) у браузері (корінь `/` автоматично спрямовує на `/uk`).

### Production-збірка та перевірка

```bash
npx tsc --noEmit
npm run lint
npm run build
npm run start
```

## Реалізовано у DEMO-версії

- **Двомовність (`UA / EN`):** маршрути `/uk/*` та `/en/*`, перемикач мови зі збереженням введених даних і активного кроку бронювання, `sitemap.xml`, `robots.txt`, метадані `hreflang` та `canonical`.
- **Головна сторінка (`/[locale]`):** асиметричний перший екран із швидким віджетом маршруту (`◉ Звідки → ■ Куди`, обмін місцями `⇄`, вибір формату й географії), авторська ілюстрація `hero-voyage.webp`, секція послуг, інтерактивний каталог категорій транспорту, 4-кроковий процес, огляд компанії та FAQ-акордеон.
- **Послуги та напрямки (`/[locale]/services`):** індивідуальні та колективні поїздки по місту, Україні й за кордон, приклади коридорів із миттєвим перенесенням у форму.
- **Категорії транспорту (`/[locale]/fleet`):** 5 класів комфорту (`Комфорт-седан`, `Бізнес-седан`, `Мінівен`, `Мікроавтобус`, `Туристичний автобус`) із мультяшними ілюстраціями замість фотографій конкретних машин та застереженням про оновлення автопарку.
- **Інтерактивне бронювання (`/[locale]/booking`):** 4 кроки (Формат і клас → Маршрут і графік → Контакти і згода → Перевірка і відправка) з підказкою щодо місткості пасажирів, блокуванням минулих дат, міжнародним форматом телефону, згодою на обробку даних (`v1.0-demo`) та **екраном підтвердження** (`UV-2026-XXXX`).
- **Про компанію, Контакти, Політика та 404 (`/[locale]/about`, `/contacts`, `/privacy`, `/not-found`).**

## Демонстраційні заглушки та обмеження (не входять у демо)

- **Вартість і доступність:** сайт не показує вигадані чи автоматично розраховані тарифи; на всіх екранах зазначено, що фінальну вартість та конкретний автомобіль підтверджує оператор.
- **DEMO-журнал заявок (`/[locale]/demo-requests`):** демонстраційне сховище (`POST /api/v1/bookings`, `PATCH /api/v1/bookings/[id]/status` + локальне збереження у браузері) замість production PostgreSQL та захищеної адмін-панелі з RBAC.
- **Не реалізовано (відкладено до узгодження):** реальна оплата картками, live GPS-трекінг, автоматичне призначення водіїв, двостороння синхронізація з `@UkrVoyazh_bot` та нативні iOS/Android застосунки.
